# 📜 Летопись — интерактивный тренажёр ЕГЭ по истории

Светлая учебная игра в славянском пиксельном стиле. Один и тот же интерфейс работает как обычный сайт, устанавливаемое PWA-приложение и Telegram Mini App.

## Что уже есть

- **Карточки:** даты и события, исторические термины, правители и деятели, войны и процессы, культура и памятники.
- **Повторение:** отметки «Знаю» и «Сложно», избранное, поиск по карточкам, фильтры и прогресс.
- **Тренажёр:** тест по датам, тест по понятиям и задания на хронологическую последовательность.
- **Карты и схемы:** последовательности ключевых этапов нашествия Батыя, Отечественной войны 1812 года и коренного перелома в Великой Отечественной войне.
- **Геймификация:** XP, серия занятий, уровни и достижения.
- **PWA:** установка на главный экран телефона или на компьютер, кеширование основных файлов для офлайн-открытия после первого запуска.
- **Telegram-бот:** команды `/start`, `/app`, `/help`, кнопка запуска Mini App и кнопка меню бота.
- **Хранение:** прогресс хранится локально в браузере через `localStorage`.

В подборке сейчас 239 учебных карточек, включая отдельный блок по всеобщей истории. Это авторская база для повторения, а не официальный открытый банк заданий ФИПИ и не полный кодификатор.

## 1. Быстрый запуск на компьютере

Нужен Python 3.

1. Распакуй архив в отдельную папку.
2. Дважды нажми `start_local.bat`.
3. Откроется `http://localhost:8080`.

Либо вручную из папки проекта:

```bash
python -m http.server 8080
```

Открой в браузере `http://localhost:8080`.

Для локальной проверки PWA используется `localhost`; полноценная установка на устройства и запуск Telegram Mini App требуют публикации сайта по HTTPS.

## 2. Сделать из сайта приложение (PWA)

Проект уже содержит `manifest.webmanifest`, значок и `sw.js`.

1. Опубликуй папку проекта на HTTPS-хостинге (например, GitHub Pages или Netlify).
2. Открой опубликованный адрес в браузере телефона или компьютера.
3. В меню браузера выбери **«Установить приложение»** или **«Добавить на главный экран»**. В Chromium-браузерах также может появиться кнопка «Установить» в верхней панели сайта.

После первого открытия основные файлы кешируются service worker и приложение сможет запускаться без сети. Для первого открытия и загрузки внешних ресурсов интернет всё же нужен.

### Публикация на GitHub Pages

1. Создай новый публичный репозиторий на GitHub.
2. Загрузи в корень репозитория содержимое этой папки: `index.html`, `styles.css`, `data.js`, `app.js`, `manifest.webmanifest`, `sw.js`, папку `assets`.
3. Открой **Settings → Pages**.
4. В блоке Build and deployment выбери **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем сохрани.
5. Через некоторое время GitHub покажет адрес примерно такого вида: `https://USERNAME.github.io/REPOSITORY/`.

Для одного HTML-приложения сборщик и npm не нужны.

## 3. Запустить Telegram-бота и Mini App

### Шаг A. Создать бота

1. Открой Telegram и найди `@BotFather`.
2. Отправь `/newbot` и пройди создание бота.
3. Скопируй выданный токен. Никому его не показывай и не публикуй в репозитории.

### Шаг B. Опубликовать Mini App

Telegram требует публичный **HTTPS URL**. Используй адрес GitHub Pages/Netlify из предыдущего раздела. Например:

```text
https://USERNAME.github.io/REPOSITORY/
```

### Шаг C. Настроить Python-бота

1. Установи Python 3.10 или новее.
2. В папке проекта скопируй `.env.example` в `.env`.
3. В `.env` вставь токен и URL опубликованного приложения:

```env
BOT_TOKEN=токен_от_BotFather
WEBAPP_URL=https://USERNAME.github.io/REPOSITORY/
```

4. Установи зависимости и запусти бота:

```bash
python -m pip install -r requirements.txt
python bot.py
```

На Windows можно запустить `start_bot.bat` после заполнения `.env`.

Теперь открой своего бота в Telegram и отправь `/start`. Кнопка **«Открыть Летопись»** запустит Mini App прямо внутри Telegram. В меню бота также появится кнопка «Летопись».

**Важно:** бот должен быть запущен на компьютере или сервере, который остаётся включённым. Для постоянной работы перенеси `bot.py` на VPS/облачный Python-хостинг и добавь переменные `BOT_TOKEN` и `WEBAPP_URL` в настройки окружения хостинга. Не загружай `.env` в GitHub.

## 4. Как обновлять карточки

Все учебные карточки лежат в `data.js` в массиве `window.CARDS`. Добавляй новые объекты по шаблону:

```js
{
  id: 'unique-id',
  type: 'dates', // dates | terms | rulers | events | culture
  era: 'Исторический период',
  front: 'Вопрос или дата',
  back: 'Краткий правильный ответ',
  hint: 'Пояснение, контекст или подсказка',
  tags: ['ключевое слово', 'тема']
}
```

`id` должен быть уникальным. Для корректного отображения карточка должна содержать `id`, `type`, `era`, `front`, `back`. После изменения `data.js` опубликуй обновлённый файл.

Схемы для режима «Карты и схемы» находятся в `window.MAP_TASKS` в том же `data.js`.

## 5. Важное про ЕГЭ-2027

В приложении отражён опубликованный ФИПИ формат на 2027 год: 22 задания и максимум 43 первичных балла. Учтены отмеченные ФИПИ изменения для истории: добавление задания №15 на исторический источник по всеобщей истории, акцент задания №20 на понимании исторического понятия и его использовании, а также аргументация по истории России в задании №22.

Сверяй актуальные требования, формулировки, критерии и полный перечень проверяемого содержания с документами ФИПИ: <https://fipi.ru/ege/demoversii-specifikacii-kodifikatory>.

Эта версия — рабочий учебный прототип. В ней есть базовая авторская подборка карточек и тренировочные мини-режимы, но нет полного официального банка заданий, автоматической проверки развёрнутых ответов по критериям ФИПИ и синхронизации прогресса между устройствами.

## 6. Как устроен проект

```text
rus_ege_quest/
├── index.html             # интерфейс приложения
├── styles.css             # оформление и адаптивная вёрстка
├── data.js                # карточки и схемы
├── app.js                 # интерактивность, тесты и прогресс
├── manifest.webmanifest   # параметры PWA
├── sw.js                  # кеширование для офлайн-режима
├── assets/favicon.svg     # значок
├── bot.py                 # Telegram-бот для открытия Mini App
├── .env.example           # шаблон настроек бота
├── requirements.txt       # зависимости Python
├── start_local.bat        # локальный веб-сервер
└── start_bot.bat          # запуск Telegram-бота
```

## Примечания

- Приложение не требует регистрации и не отправляет учебные отметки на сервер.
- Данные `localStorage` привязаны к конкретному браузеру/контексту. Прогресс в обычном браузере и внутри Telegram может быть раздельным. Для общей синхронизации понадобится отдельный backend с проверкой Telegram `initData` и авторизацией пользователя.
- Внешний Google Fonts используется только как декоративное улучшение; если он недоступен, включатся системные шрифты.
